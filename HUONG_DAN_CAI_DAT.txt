╔══════════════════════════════════════════════════════════════════════╗
║  BƯỚC 1: CÀI ĐẶT PHẦN MỀM CHẠY WEB (NẾU CHƯA CÓ)                ║
╚══════════════════════════════════════════════════════════════════════╝

1. Tải XAMPP tại: https://www.apachefriends.org/download.html
   - Chọn phiên bản PHP 8.1 hoặc 8.2 cho Windows.
   - Cài đặt mặc định (Next -> Next -> Install).

2. Sau khi cài xong, mở XAMPP Control Panel:
   - Nhấn nút "Start" ở hàng Apache  -> Cột Status sáng xanh là OK.
   - Nhấn nút "Start" ở hàng MySQL   -> Cột Status sáng xanh là OK.

   LƯU Ý QUAN TRỌNG VỀ CỔNG (PORT):
   - Apache mặc định chạy cổng 80. Nếu máy bạn bị trùng cổng 80
     (ví dụ Skype, IIS...), XAMPP sẽ báo lỗi. Khi đó hãy đổi cổng
     Apache sang 83 hoặc 8080 (vào Config -> httpd.conf -> tìm
     "Listen 80" đổi thành "Listen 83").
   - MySQL mặc định chạy cổng 3306.


╔══════════════════════════════════════════════════════════════════════╗
║  BƯỚC 2: COPY MÃ NGUỒN WEBSITE                                     ║
╚══════════════════════════════════════════════════════════════════════╝

1. Giải nén file "webphim_hung.zip" (file bạn nhận được).
2. Copy thư mục "webphim_hung" vào thư mục htdocs của XAMPP:
   
   C:\xampp\htdocs\webphim_hung

   (Nếu bạn cài XAMPP ở ổ khác thì thay "C:\xampp" bằng đường dẫn
   XAMPP của bạn).


╔══════════════════════════════════════════════════════════════════════╗
║  BƯỚC 3: TẠO DATABASE VÀ IMPORT DỮ LIỆU                           ║
╚══════════════════════════════════════════════════════════════════════╝

1. Mở trình duyệt, truy cập: http://localhost/phpmyadmin/
   (Hoặc http://localhost:83/phpmyadmin/ nếu bạn đổi cổng Apache)

2. Tạo Database mới:
   - Click "New" (Mới) ở cột trái.
   - Đặt tên database: cinepass
   - Chọn Collation: utf8mb4_general_ci
   - Nhấn "Create" (Tạo).

3. Import dữ liệu:
   - Click chọn database "cinepass" vừa tạo ở cột trái.
   - Chọn tab "Import" (Nhập) ở thanh menu trên.
   - Nhấn "Choose File" (Chọn file), duyệt đến:
     C:\xampp\htdocs\webphim_hung\DB\cinepass.sql
   - Nhấn nút "Import" / "Go" ở dưới cùng để nạp dữ liệu.
   - Đợi cho đến khi thông báo thành công (Success) hiển thị.


╔══════════════════════════════════════════════════════════════════════╗
║  BƯỚC 4: CẤU HÌNH KẾT NỐI DATABASE (ĐÃ TỰ ĐỘNG)                      ║
╚══════════════════════════════════════════════════════════════════════╝

   *** HỆ THỐNG ĐÃ CÓ TÍNH NĂNG TỰ ĐỘNG NHẬN DIỆN CỔNG MYSQL ***
   Hẹ thống sẽ tự động thử kết nối cổng 3306 trước, nếu không được
